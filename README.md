## 🅿️ Featured Project — Predictive Smart Parking Ecosystem

An intelligent parking platform designed to make finding, predicting and booking parking spaces easier.

### 🔥 Key Features

* 📍 Live user location
* 🗺️ Interactive parking map
* 🅿️ Real-time parking availability
* 🔮 Parking availability prediction
* 💰 Dynamic & surge pricing
* 📅 Parking reservation system
* 🔔 Real-time updates
* 📊 Prediction & analytics dashboard
* 👨‍💼 Admin dashboard
* 🔐 User authentication
* 📡 WebSocket-based communication
* 🗄️ PostgreSQL + PostGIS geospatial database
* ⚡ Kafka event-driven architecture
* 🤖 Python ML prediction layer
* 🐳 Dockerized services
* 📈 Prometheus & Grafana monitoring
* 🔄 GitHub Actions CI workflow

### 🧰 Architecture

| Layer | Stack |
|---|---|
| **Frontend** | React + TypeScript + Tailwind CSS + Zustand |
| **Backend** | Java 21 + Spring Boot + Spring WebFlux + REST APIs + WebSockets |
| **Database** | PostgreSQL + PostGIS |
| **AI/ML** | Python + FastAPI + Scikit-learn |
| **Infrastructure** | Docker + Kafka + Prometheus + Grafana + GitHub Actions |

> 🚀 This project is one of my main portfolio projects, combining full-stack development, geospatial technology, real-time systems and machine learning.
